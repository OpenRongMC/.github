# OpenRongMC

简体中文 · [English](https://github.com/OpenRongMC/.github/blob/main/profile/README.en.md)

OpenRongMC 维护 RongMC 建筑服使用的 Minecraft Java 模组、交通与城建移植，以及配套客户端工具。当前发行以 **Minecraft 26.3、Fabric 和 Java 25** 为目标。
